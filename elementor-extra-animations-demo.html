Independent triggers

Two widgets, one section, two delays

Both widgets sit in the same section, but each has its own Entrance Animation and its own Animation Delay — set with Elementor's native delay field, nothing custom. They fire independently the moment each one crosses into view.

What actually happened above

Every block above started at opacity:0, hidden by elementor-invisible. Nothing changed until the block's own boundary crossed into the viewport — at that point JS swapped in animated, which is the class our CSS keyframes are keyed on.

  • The trigger belongs to the element with the animation set — a wrapping section doesn't inherit it from a widget inside it.
  • By default it plays once. Scrolling back up and down again in a live Elementor page won't replay it.
  • Duration and delay come entirely from Elementor's own native fields, which is why Widget B above waited an extra 250ms before starting.
